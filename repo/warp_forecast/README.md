# 抽卡资源预测

用于估算当前版本还可以获得多少抽，以及到版本结束时预计拥有多少抽卡资源。

脚本优先使用自动 OCR：

- 背包资源：星琼、星轨专票、星轨通票。
- 旅情事记/奖励指南：包含“剩余”的星琼或票据奖励。

如果 OCR 失败，可以关闭自动识别并填写手动资源值。版本进度计算不依赖联网：

- 版本结束日期 = 版本起始日期 + 版本持续天数，默认 42 天。
- 下一版本前瞻日期 = 版本结束日期 - 前瞻提前天数，默认提前 12 天。
- 深渊类奖励按刷新间隔计算，默认每 14 天一次，每次 800 星琼。
- 每周模拟宇宙/差分宇宙/货币战争奖励默认 225 星琼。

建议每个版本开始后手动设置一次“版本起始日期”。如果实际深渊或周常刷新节奏与脚本计算不一致，可以使用“剩余次数覆盖”直接指定次数。
