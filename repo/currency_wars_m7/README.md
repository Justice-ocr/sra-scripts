# 货币战争（三月七）

调用 March7thAssistant 的货币战争功能，可在 SRA 脚本配置页中设置模式、职级难度、策略、奖励领取和运行方式。

## 使用前准备

- 先安装并至少启动过一次 March7thAssistant，完成它的首次初始化。
- 在脚本配置中把“三月七安装目录”指向包含 `March7th Assistant.exe` 的目录。
- 建议不要在三月七正在执行其它任务时运行本脚本。

## 运行方式

- `normal`：调用三月七 `currencywars`，从货币战争入口开始执行。
- `temp`：调用三月七 `currencywarstemp`，接管已经在货币战争中的当前局。
- `loop`：调用三月七 `currencywarsloop`，由三月七内部循环执行，通常需要手动停止。

## 配置保护

March7thAssistant 当前没有为货币战争配置提供命令行参数，本脚本会临时修改三月七的 `config.yaml`。默认会在任务结束、失败、超时或手动停止时恢复原配置，避免影响三月七自身功能。

默认不允许在三月七已运行时启动。如果确认三月七没有其它任务，才建议打开“允许三月七已运行”。
